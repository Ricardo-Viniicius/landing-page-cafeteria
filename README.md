☕ Projeto: Landing Page - Rick Coffee
Este é um projeto desenvolvido para praticar a criação de interfaces modernas e atrativas. Trata-se de uma landing page institucional para a cafeteria Rick Coffee, criada para apresentar a marca, destacar o café artesanal e consolidar meus estudos em desenvolvimento web.

![Preview do Projeto](./preview.png)

📝 Sobre o Projeto

O objetivo deste projeto foi aplicar conceitos fundamentais de design e estruturação para a web. Através dele, trabalhei a construção de uma interface imersiva em tom escuro (dark mode / tons terrosos), focando na boa apresentação visual, hierarquia de informações e navegação fluida para o usuário.

🛠 Tecnologias Utilizadas

HTML5: Utilizado para a estrutura semântica da página, incluindo cabeçalho, seções de conteúdo e botões.

CSS3: Aplicado para a estilização visual, criação de layout, trabalho com opacidade em imagens de fundo e tipografia.

🚀 O que eu pratiquei:

Criação de Hero Section com imagem de fundo e sobreposição de texto.

Construção de menu de navegação e barra superior (header).

Posicionamento e alinhamento de elementos com CSS (Flexbox / Grid).

Estilização de botões de chamada para ação (Call-To-Action).

Organização de arquivos e versionamento com Git e GitHub.
